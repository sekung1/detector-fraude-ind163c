¿Cómo leer este resultado?

El modelo ({{ meta.modelo }}) entrega un puntaje de riesgo de 0 a 100. Si llega a {{ '%.0f' % umbral_pct }} o más, la transacción se marca como posible fraude. Un puntaje entre 50 y {{ '%.0f' % umbral_pct }} indica un riesgo sobre el promedio (riesgo medio).

El puntaje no es una probabilidad: el modelo se entrenó dando más peso a los fraudes (porque son solo el {{ '%.1f' % (meta.tasa_fraude_global * 100) }}% de los casos), así que sus valores sirven para ordenar el riesgo, no para leerlos como porcentaje. La frecuencia real de fraude se muestra en el contexto histórico.

En el conjunto de prueba, con este umbral, el modelo detectó el {{ '%.0f' % (meta.metricas_test.Sensitivity * 100) }}% de los fraudes (Sensitivity) y dejó pasar sin alertas al {{ '%.0f' % (meta.metricas_test.Specificity * 100) }}% de las transacciones legítimas (Specificity). Es una herramienta de apoyo: las alertas deben revisarse.
